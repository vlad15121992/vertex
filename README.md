## Робота сайту

Статичні HTML, CSS та JavaScript. Без Base44, API, платних пакетів і збирання. Усі зображення та шрифти зберігаються в `assets/`. Навігація, фільтри портфоліо, повноекранна галерея й слайдер ескізу/візуалізації працюють локально.

Для доставки потрібно натиснути «Надіслати» у Telegram; копіювання залишається запасним способом. Сайт не відправляє заявки автоматично, не зберігає персональні дані в базі чи в локальному сховищі та не показує фальшивого підтвердження доставки. Телефон: +380689986411, контакт: Михайло Вишневий.

## Зміни

Тексти та роботи: `index.html`; оформлення: `styles.css`; взаємодія: `app.js`. Замінюйте локальні зображення у `assets/`. Контакти задані в `index.html`; адреса чату з текстом заявки також задана в `app.js`. Для іншого Telegram оновіть усі посилання в обох файлах.
